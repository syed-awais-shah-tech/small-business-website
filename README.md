# Portfolio Project 3: Small Business Website & Customer Form

Responsive landing page and demo inquiry form for **Awais Laptop Shop**.

## Overview
This project demonstrates the core building blocks of front-end web development and explores how customer inquiries captured on the web translate to CRM / Lead data in an ERP like **Odoo**.

## File Structure
- `index.html`: Defines the layout, semantics, and markup of the page.
- `style.css`: Provides styling, typography, responsive card layouts, and form aesthetics.
- `script.js`: Handles form validation, prevents page reload on submit, displays confirmation, and resets fields.

## How to Run
Open `index.html` directly in any web browser.
